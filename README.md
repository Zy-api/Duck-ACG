## 简介

Duck 动漫把找剧、看剧和收藏放进一个轻量的客户端：首页按「推荐 / 动漫 / 电影 / 电视剧」分类浏览，支持排行榜、收藏和在线播放；登录后还可以同步账号与会员信息。

## 功能

- 分类浏览：推荐、动漫、电影、电视剧
- 排行榜：热门作品一目了然
- 收藏：想看的内容随时找回
- 在线播放：内置播放器，点开即看
- 账号体系：注册登录、邮箱验证、修改密码
- 会员中心：VIP / SVIP 档位、密钥兑换
- 多设备管理：查看登录设备，异常设备及时处理

## 下载

前往 [Releases](https://github.com/Zy-api/Duck-ACG/releases/latest) 下载最新 APK。

- 最新版本：3.5.1（versionCode 632）
- 系统要求：Android 8.0 及以上
- 架构：arm64-v8a

## 安装

1. 下载 `Duck-ACG-3.5.1-632.apk`
2. 在系统设置中允许「安装未知来源应用」
3. 安装并打开

覆盖安装时若提示签名不一致，请先卸载旧版本再安装。
